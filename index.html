1. CPU — Central Processing Unit

Otak Utama Pemrosesan Sistem

Pengertian

CPU (Central Processing Unit) adalah komponen komputer yang bertugas memproses instruksi dan mengolah data. CPU sering disebut sebagai “otak komputer” karena hampir semua perintah yang dijalankan komputer diproses oleh CPU.

Fungsi CPU

  • Mengolah data dan instruksi.
  • Menjalankan perintah dari software.
  • Melakukan perhitungan matematika dan logika.
  • Mengatur jalannya berbagai proses komputer.
  • Berkomunikasi dengan komponen lain seperti RAM, storage, dan perangkat input/output.
Contoh Alur Eksekusi CPU:

Ketika kita membuka Microsoft Word dan mengetik:

Keyboard CPU memproses RAM Monitor menampilkan tulisan

2. GPU — Graphics Processing Unit

Spesialis Pemrosesan Tampilan & Grafis Visual

Pengertian

GPU (Graphics Processing Unit) adalah komponen yang dirancang khusus untuk memproses dan menghasilkan tampilan grafis. GPU sangat penting ketika komputer menjalankan pekerjaan yang membutuhkan pengolahan gambar dalam jumlah besar.

Fungsi GPU

  • Mengolah gambar dan video.
  • Menghasilkan tampilan grafis pada monitor.
  • Memproses animasi dan grafis 3D.
  • Membantu menjalankan game.
  • Mempercepat pekerjaan desain, editing video, dan aplikasi grafis tertentu.
Contoh Penggunaan GPU:

GPU bekerja lebih berat ketika kita:

Bermain game 3D 🎮
Mengedit video 🎬
Membuat desain grafis 🎨
Membuat animasi 3D
Menggunakan aplikasi 3D
💡 Perbedaan CPU dan GPU
CPU (Central Processing Unit) Serbaguna dan menangani berbagai jenis tugas komputer.
GPU (Graphics Processing Unit) Dirancang khusus untuk menangani pemrosesan grafis secara cepat dan paralel.

3. RAM — Random Access Memory

Memori Kerja Sementara Berkecepatan Tinggi

Pengertian

RAM (Random Access Memory) adalah memori yang digunakan komputer untuk menyimpan data dan program yang sedang digunakan sementara.

RAM bersifat sementara (volatile). Artinya, data yang ada di RAM akan hilang ketika komputer dimatikan.

Fungsi RAM

  • Menyimpan data sementara.
  • Menyimpan program yang sedang dijalankan.
  • Membantu CPU mengakses data dengan cepat.
  • Memungkinkan komputer menjalankan beberapa aplikasi sekaligus.
Contoh Penggunaan RAM

Misalnya kita membuka aplikasi secara bersamaan:

Chrome Word Excel Canva

Keempat aplikasi tersebut membutuhkan RAM untuk menyimpan data yang sedang digunakan. Jika RAM terlalu kecil, komputer dapat terasa lambat atau tersendat ketika banyak aplikasi dibuka.

Kapasitas RAM

RAM biasanya memiliki kapasitas:

4 GB → 8 GB → 16 GB → 32 GB → 64 GB, dsb.

Semakin besar RAM tidak selalu berarti komputer otomatis lebih cepat, tetapi kapasitas yang lebih besar memungkinkan lebih banyak data/program aktif ditampung secara bersamaan.

4. Storage Device

Perangkat Penyimpanan Jangka Panjang (Non-Volatile)

Pengertian

Storage device (perangkat penyimpanan) adalah perangkat yang digunakan untuk menyimpan data dan program dalam jangka panjang. Berbeda dengan RAM, data pada storage tetap tersimpan meskipun komputer dimatikan.

Contoh Storage Device & Jenisnya:

💾
A. HDD — Hard Disk Drive

Penyimpanan Magnetik

HDD menggunakan piringan magnetik yang berputar untuk menyimpan data.

Fungsi:
  • Menyimpan sistem operasi.
  • Menyimpan aplikasi.
  • Menyimpan dokumen.
  • Menyimpan foto, video, dan musik.
⚡
B. SSD — Solid State Drive

Penyimpanan Memori Flash

SSD menggunakan memori flash untuk menyimpan data dan tidak memiliki piringan yang berputar.

Fungsi:
  • Menyimpan sistem operasi dan aplikasi.
  • Menyimpan dokumen dan file.
  • Membuat proses membaca dan menulis data lebih cepat dibandingkan HDD pada banyak kondisi.
🔌
C. Flashdisk

Penyimpanan Portabel USB

Perangkat penyimpanan berukuran kecil yang mudah dibawa.

Fungsi:
  • Memindahkan file.
  • Menyimpan dokumen, foto, video, dan data lainnya.
📱
D. Memory Card

Penyimpanan Kompak Perangkat

Media penyimpanan kecil yang banyak digunakan pada perangkat portabel.

Banyak digunakan pada:
  • Kamera
  • Smartphone
  • Tablet
  • Perangkat elektronik lainnya.
🔄

Bagaimana Keempat Komponen Ini Bekerja Bersama?

1

2

⬇️ Menampung data Word yang sedang digunakan agar mudah diakses.

3
CPU

⬇️ Memproses perintah ketikan dan pengolahan data.

4
GPU

⬇️ Membantu menghasilkan tampilan grafis antarmuka Word.

5
Monitor

⬇️ Menampilkan hasil dokumen Word kepada pengguna.
